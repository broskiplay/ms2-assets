# ms2-assets

Тайлы и картинки для интерактивной карты [Mortal Shell II](https://broskiplay.ru/mortal-shell-2-map/) (BroskiPlay). Раздаются через GitHub Pages.

- `tiles/fallgrim/<z>/<x>/<y>.webp` (256×256, z8–z15, сетка MapGenie, WebP q90) и `manifest.json` — список существующих тайлов
- `popups/<id>.webp` — картинки к меткам (WebP q90, не больше 1920×1080)
